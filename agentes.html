Las mismas herramientas, para su código o su agente de IA

Todas las herramientas de este sitio usan una sola biblioteca de JavaScript, sin dependencias, que funciona igual en el navegador, en Node y en Deno. Es determinista: la misma entrada da siempre la misma salida, sin IA y sin costo por uso.

Código abierto

Todo el código está publicado con licencia MIT en github.com/AVEjecutivo/herramientas-pyme: la biblioteca, sus pruebas, los ejemplos ficticios y un servidor MCP.

Conectarlo a su asistente (servidor MCP)

Con el servidor MCP, su asistente de IA puede leer sus facturas y cartolas directamente desde su computador y responder con números exactos. Requiere Node.js 18.17 o superior. Nada se envía a servidores externos.

Claude Code

claude mcp add herramientas-pyme -- npx -y github:AVEjecutivo/herramientas-pyme

Claude Desktop

En Configuración › Desarrollador › Editar configuración, agregue a claude_desktop_config.json:

{
  "mcpServers": {
    "herramientas-pyme": { "command": "npx", "args": ["-y", "github:AVEjecutivo/herramientas-pyme"] }
  }
}

Luego puede pedirle, por ejemplo: "Cruza la cartola de julio con mis Registros de Compras y Ventas y dime qué está pendiente" o "Estima mi F29 de junio".

Cómo usarla

En el navegador o en Deno

import { leerDTE, leerCartola, conciliar } from "https://miavejecutivo.com/herramientas/lib/ave-herramientas.js";

const facturas = leerDTE(textoXML, "factura.xml");
const { movimientos } = leerCartola(textoCSV, "cartola-bci.csv");

En Node (18 o superior)

curl -O https://miavejecutivo.com/herramientas/lib/ave-herramientas.js

// script.mjs
import { leerRegistroSII, estimarF29 } from "./ave-herramientas.js";
import { readFileSync } from "node:fs";
const ventas = leerRegistroSII(readFileSync("RegistroVentas.csv", "utf8"));

Formato de una fila de factura

{
  "archivo": "factura.xml", "tipo_dte": "33", "tipo_documento": "Factura electrónica",
  "folio": "1043", "fecha_emision": "2026-06-02",
  "rut_emisor": "76.123.456-0", "razon_social_emisor": "…",
  "rut_receptor": "76.980.417-3", "razon_social_receptor": "…",
  "monto_neto": 6400000, "monto_exento": 0, "iva": 1216000, "monto_total": 7616000,
  "origen": "xml | pdf | ocr | ia | registro_ventas | registro_compras",
  "confianza": "alta | media | baja", "observaciones": ""

Fechas en formato ISO (aaaa-mm-dd), montos como enteros en pesos y RUT con puntos y guion.
